作業報告書アプリ

三和テック株式会社　初回設定

1

Supabaseに登録（無料）

supabase.com にアクセスして「Start your project」→ 無料アカウントを作成します。

2

新しいプロジェクトを作成

「New project」→ プロジェクト名（例: sanwa-report）を入力 → 「Create new project」をクリック。

3

SQLを実行してテーブルを作成

左メニューの「SQL Editor」→「New query」を開いて、以下をコピー＆貼り付けして「Run」を押します。

create table reports ( id uuid default gen_random_uuid() primary key, created_at timestamptz default now(), report_date date not null default current_date, technician_name text default '', customer_name text default '', customer_address text default '', customer_phone text default '', pest_types jsonb default '[]', pest_other text default '', work_types jsonb default '[]', work_other text default '', warranty_period text default 'なし', warranty_start date, warranty_end date, notes text default '', signature_data text default '', signed_at timestamptz, share_token uuid default gen_random_uuid(), created_by uuid references auth.users(id) ); alter table reports enable row level security; create policy "auth_all" on reports for all to authenticated using (true) with check (true); create policy "anon_read" on reports for select to anon using (true);
4

スタッフアカウントを作成

左メニュー「Authentication」→「Users」→「Invite user」→ スタッフのメールアドレスを入力して招待（3名分繰り返す）。招待メールのリンクからパスワードを設定します。

5

APIキーを貼り付ける

左メニュー「Project Settings」→「API」→「Project URL」と「anon public」キーをコピーして下に入力します。

設定はこの端末に保存されます
